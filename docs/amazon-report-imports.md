# 亚马逊销售与广告导入

当前支持用户提供的亚马逊订单 TXT 和中文「商品推广－推广的商品」XLSX 格式。无需另填模板或修改表头。

2026-09-09 [灵活作业设计](weekly-operations-workflow.md) 规划每天15:00下载经营数据和周五销售/库存分析待办，并保留商品周表、报告时区/覆盖、版本及FBA快照等后续能力。提醒可改期或取消，随时可以导入/分析，不以待办完成作为前置；这些增强尚未实现，下文仍记录当前导入及日期筛选行为。

## 操作步骤

1. 打开「数据导入中心」，选择「导入销售数据」或「导入广告数据」。
2. 选择文件实际所属店铺并上传原始报告。文件最多 20 MB、10000 行。
3. 查看新增、更新、跳过、冲突和文件内重复数量；可筛选预览行，错误标注源行号。
4. 核对后点击「确认导入」。有错误或冲突时整批不写入，修正后重新上传。预览后其他人更新了数据，系统会要求刷新预览并再次确认。
5. 在「销售记录」或「广告数据」查看明细、搜索、日期和店铺筛选，以及币种汇总。点击记录可查看规范字段，点击「批次 · 行」可追溯来源。

上传和预览会保存批次，但不会改动销售或广告记录。确认后的批次保留处理数量和来源；再次点击确认或网络重试不会重复入库。文件内相同行的合并数量与「跳过已有」分别展示。

首次查看默认全部日期。销售按 UTC 下单日期筛选；广告默认显示「日报」，按源报告日期筛选。旧版多日汇总可切换「历史区间」查看，其区间须完整落在筛选范围内，不拆成日报，也不与日报合计。

点击「日期」区间输入框展开双月日历，按顺序选择开始和结束日期，选完自动应用并关闭。输入框显示 `YYYY/MM/DD → YYYY/MM/DD`，也支持直接输入日期。弹层左侧提供 **最近7天、最近3天、今天、最近30天、本周、上周、本月、上月、今年以来** 九个快捷入口，点击后立即应用。已有 SKU/关键词、店铺、状态和广告粒度筛选继续生效。

快捷区间按浏览器所在设备的本地日历计算。左侧「含当天」默认勾选，控制最近 3/7/30 天是否包含今天；取消后最近 N 天截至昨天，不改变「今天」及周/月/年等固定周期。每周从周一开始，本周、本月和今年以来截至今天，上周取完整周一至周日，上月取整月。手动选定区间会取消快捷高亮；点输入框清除按钮或「全部日期」恢复全部记录。未完成的手选可按 Esc 取消；只改一端后再选快捷项，以最后选中的快捷范围为准。

## SKU 候选搜索

销售记录和广告数据共用相同的搜索方式：

1. 点击空搜索框，显示当前授权店铺、日期及状态/广告粒度范围内的去重 SKU 列表。
2. 输入内容后，候选按 SKU 包含匹配，大小写不敏感；输入过程中明细和汇总保持原查询结果。
3. 点击候选或用方向键选中后按回车，立即按该 SKU 精确搜索明细和汇总，例如选择 `SKU-A` 不会包含 `SKU-AB`。
4. 也可直接按回车或点击搜索按钮，确认普通关键词搜索；点击输入框的清除按钮恢复全部记录，其他筛选条件仍生效。

候选最多显示 50 个，超过时会提示继续输入缩小范围。无匹配 SKU 时仍可确认关键词，搜索订单号、ASIN、商品名称或广告活动等原有字段。广告「日报」与「历史区间」各自提供对应数据中的 SKU。

## 销售格式与重复处理

支持 UTF-8（含 BOM）或 UTF-16 编码的制表符 TXT/TSV。必需列：

```text
amazon-order-id, purchase-date, last-updated-date, order-status,
fulfillment-channel, sales-channel, product-name, sku, asin,
item-status, quantity, currency, item-price
```

同时保留 merchant-order-id、商品税费、运费及运费税、包装费及包装税、商品优惠和运费优惠。表头前后空格会清理；数量必须是非负整数，时间必须带时区；金额按四位小数保存，缺失金额保留为空。

销售身份为 **店铺 + sales-channel + amazon-order-id + sku**，与文件名和上传账号无关。

| 情况 | 处理 |
|---|---|
| 同文件内相同身份、相同规范内容 | 合并，只保留一行 |
| 同文件内相同身份、内容不同 | 报冲突，不猜测为同 SKU 拆行 |
| 已有相同身份、相同内容 | 跳过，不增加数量或金额 |
| 已有相同身份，新报告更新时间更晚 | 更新原记录及来源，不新建第二行 |
| 已有相同身份，新报告更新时间更早 | 跳过，保留较新记录 |
| 已有相同身份，更新时间相同但内容不同 | 报冲突，整批暂不导入 |

因此相同文件、改文件名和重叠日期导出的文件都能去重。不同店铺或销售渠道保留独立身份。样本没有 order-item-id；遇到同订单同 SKU 的不同拆行，需要先核对来源，当前不会自行合并金额。

不含税净额 = item-price + shipping-price + gift-wrap-price − item-promotion-discount − ship-promotion-discount。item-price 是源行金额，**不再乘 quantity**。无商品金额时净额为空；取消或待处理订单按状态分组，币种为空时展示「未提供」。USD/CAD 等币种分别汇总。这里展示订单报告金额，不是结算收入或利润。

## 广告格式与重复处理

支持一张工作表的 XLSX，使用「日期」列，或相同的「开始日期」「结束日期」表示日报。其他中文字段沿用广告组合、货币、活动、广告组、零售商、国家/地区、广告 SKU/ASIN，以及展示、点击、花费、7 天总销售额/订单数/销售量、广告 SKU 与其他 SKU 的销售额/销售量。可读取 Excel 日期和 YYYY-MM-DD；兼容旧样本错误的工作表范围信息。日期列和起止日期同时出现时必须一致。

日报去重身份为 **店铺 + 日期 + SKU + 广告活动名称 + 广告组名称**，保留 **7 天归因窗口**：

- 同一天、同 SKU、同活动和广告组：新导入覆盖旧指标与属性，不能累加；相同内容跳过。ASIN、币种、国家、零售商和组合变化仍更新同一条记录。
- 不同日期、店铺、SKU、活动或广告组分别保存。同一文件内重复时保留最后一行，预览显示「文件内合并重复行」和最后源行号。
- 更晚上传且已确认的报告优先；即使指标相同而跳过，也会记录最新确认的上传时间，防止较早待确认批次覆盖它。报告本身不含生成时间，重新上传一个旧文件仍视为新上传版本，确认前需核对指标。
- 活动/广告组名称属于身份，重命名视为不同记录，当前不能自动关联。

旧版起止日期不同的多日汇总继续按原维度与完整区间处理，仅在「历史区间」查询和汇总：相同身份同区间替换，不同重叠区间拒绝。本次迁移将旧单日记录转为日报并去重，按最新上传版本、同批次最后源行保留，原确认批次留存追溯。新版上线前尚未确认的广告批次需要重新上传，避免沿用旧去重键；已确认的批次仍可查看。

汇总按币种分别计算：CTR = 点击 / 展示，CPC = 花费 / 点击，ACOS = 花费 / 归因销售额，ROAS = 归因销售额 / 花费。零分母显示为空；不直接平均报告中的比率。广告归因销售额独立展示，不加到订单销售额。

## 权限、文件与边界

管理员、店铺主管、运营和财务可在授权店铺内查看、导入；只有上传者可确认自己的批次。仓库角色没有报表权限。店铺停用或授权被撤销后不能继续确认。

原始文件以随机存储名保存在配置的私有文件目录，文件权限为 600，不作为公开附件提供下载。页面及报表 API 仅返回规范业务字段，不返回原文件中的收件地址、邮编或买家标识。备份报表需同时备份数据库和私有文件目录。

禁止宏、公式和损坏的 XLSX；解压最多 50 MB、1000 个文件项；表最多 80 列。解析失败或确认冲突不会部分写入事实表。

当前按原 Seller SKU/ASIN 保存，未自动关联内部商品，也不会扣库存、生成成本或利润。其他广告归因窗口、搜索词、结算、库存快照及退款等报告需另行适配。正式导入请由用户选择实际店铺并确认。
