# 工作台待办与提醒

2026-09-09 · W0 使用说明

工作台集中安排人的事项。采购、销售分析和发货可以随时进入，不要求先完成待办。待办的完成、取消、改期不会生成采购、发货或库存流水。

## 开始使用

进入 **经营工作台 → 提醒规则 → 添加推荐提醒**，选择个人或单店范围及需要的模板。每个账号自行启用，重复添加同范围模板不会覆盖已修改或已暂停的设置；升级不会给旧单据批量补提醒。

| 模板 | 默认安排 | 结束方式 |
|---|---|---|
| 下载经营数据 | 每天含周末 15:00 | 手动完成；可打开数据导入中心 |
| 分析销售数据与库存情况 | 每周五全天 | 手动完成；可打开销售页面，工作台另有库存入口 |
| 向供应商下单 | 新建采购后首个周一 09:00，单次 | 手动完成，或登记已向供应商下单 |
| 确认生产进度 | 预计发货前 2 个自然日，全天 | 手动完成，或采购详情记录生产确认 |
| 跟进发货 | 预计发货当天，全天 | 手动完成，或记录对应货件实际发出 |

时区默认 `Asia/Shanghai`。周一 09:00 尚未过去时，下单事项取当天，否则取下一周一。全天事项在当天结束后才逾期；设置具体时间的事项到时逾期，并可产生站内通知。仅设置日期的全天事项不在午夜发通知。

规则可编辑标题、星期、时刻、时区、日期偏移、通知开关，也可暂停。周期事项提前展示未来 7 天。修改规则只影响之后新生成的实例，已展示的事项保留原安排，可逐条调整；暂停规则停止新增，已有事项可单独取消。恢复规则不补暂停期间的新实例。

## 按实际工作安排

- **新建待办**：填写标题即可，日期和店铺都可留空。管理员、主管可以按权限委派负责人。
- **完成 / 取消 / 恢复**：只处理这一次事项，下一次周期事项继续按规则生成。
- **调整**：可改日期、时间、备注、负责人或通知开关。多人同时编辑时，陈旧版本会提示刷新，不覆盖他人修改。
- **逾期 / 今天 / 未来 / 未定日期**：按安排时间分组，支持搜索、分页以及本人或可访问范围筛选。
- **查看记录**：点击待办标题查看最近变更。阅读通知、打开业务页面、导入一个文件都不会自动完成分析或下载事项。

个人周期事项在“全部店铺”下查看；指定店铺的待办跟随顶部店铺筛选。提醒规则页展示当前账号所有可访问的规则，并逐条标明适用范围。

## 采购和发货

采购与货件新增独立的 **预计发货日**，现有 **预计到货日**继续保留。没有预计发货日也能保存，相关提醒显示“未定日期”。采购创建可选择“已向供应商下单”补录事实；系统不会代替你发送订单。

采购详情可以调整预计发货日、登记生产确认、添加关联待办、为历史单据应用已启用的规则。记录生产确认保留说明和操作人；普通采购备注不算生产确认。

生产和发货提醒默认跟随单据日期。要单独安排时，关闭“日期跟随单据预计发货日”再改期；以后单据改期会提示，保留这次手动安排。已完成或已取消的事项不会因单据改期复活。

同一采购可以建立多个货件，按每批实际数量跟进。货件未填预计发货日时跟随采购单；填了日期则使用本批日期。已经分配给有提醒货件的数量由货件提醒覆盖，采购余量继续保留跟进；全部发出后采购发货事项才自动完成。取消未发货件后，释放的采购余量重新显示在采购提醒中。手动完成的事项不改变任何数量。

当前仍按已有货件模型安排分批：本批确定 50 件，就建立 50 件货件；“已建 60 件计划内只实发 50 件”的进一步拆分能力按 W4 建设。

## 运行和权限

待办由独立 `scheduler` 进程处理，浏览器关闭不影响生成。服务运行时约每 10 秒处理一轮，页面可见时每 30 秒刷新；电脑关机或服务停止期间无法准时提醒，恢复后补齐启用期间的事项并合并通知。单据同步失败时工作台提示，后台单独退避重试，不阻止其它事项生成。

待办、单据、汇总通知均复核当前账号和店铺权限。转派已到期事项会向新负责人重新提醒，收回店铺权限后不能再打开相应待办或通知。手动待办与实际业务事实保持独立。

当前通知方式为 ERP 站内通知；没有添加邮件、短信、微信或 Codex 自动化。FBA 外部库存快照、补货计算和财务增强继续按开发计划推进。
