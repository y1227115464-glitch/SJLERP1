# 采购、发货与库存管理

本模块已接入现有账号、店铺授权、商品和供应商档案。入口为左侧「采购记录」「发货进度」「库存管理」。

2026-09-09 [工作流改版设计](weekly-operations-workflow.md) 调整为独立业务操作与关联待办：采购下单、生产进度及发货可按规则提醒，允许改期、取消和跳过跟进，预计发货与预计到货分开。提醒和计划内部分实发等增强尚未实现，本文下方仍说明当前可用操作；文档修改不改变现有整张计划确认发出的行为。

## 开始使用

1. 建立实际店铺、商品和供应商。
2. 在「库存管理 → 仓库档案」建立国内仓、海外仓或 FBA 目的仓。
3. 现有库存通过「期初 / 库存调整」登记；填写实际数量、所属店铺和原因。
4. 新购货物从采购单开始，不再重复登记为期初库存。

仓库档案公司共享；货权通过店铺区分。同一商品、同一仓库可以分别持有不同店铺的库存，不能通过改店铺字段转移货权。顶部经营日期不影响这些业务记录；店铺筛选影响采购、货件、库存和流水。仓库档案不受店铺筛选影响。

## 采购记录

新增采购单时填写店铺、供应商、采购日期、商品、整数数量、单价和币种，可以补充交期、付款约定和备注。单价保留四位小数，采购金额使用十进制定点计算。

草稿可以修改。提交后锁定商品、数量和金额，可在详情中「安排供应商发货」。同一采购单可以拆为多批，每批只填写实际发货数量。

可安排数量 = 采购数量 − 已到货数量 − 已取消数量 − 已分配待发/在途数量。

「取消未分配余量」只取消尚未安排发货的部分，不影响已有待发或在途货件。已收货与已取消合计覆盖采购数量后，单据显示「全部到货」「余量已取消」或「已取消」。采购金额仍表示原始下单金额，已取消数量单独保留；付款约定只是记录，不生成应付核销或付款流水。

## 发货进度

支持两条路线：

- 供应商 → 国内/海外/FBA 仓：从已提交且尚有余量的采购单安排发货。供应商直发 FBA 时直接选择 FBA 目的仓，无须虚构国内仓入出库。
- 仓库 → FBA/其他仓库：选择发货仓、目的仓和商品，保存计划时占用可用库存。

货件可登记承运商、物流运单、Amazon Shipment ID、预计到货和备注。Amazon 货件仍由人员在卖家后台创建，ERP 记录其编号。

1. 「确认发出」：货件进入在途；仓库发货扣减源仓实物并释放相应占用。
2. 「登记进度」：更新运输中、清关中、已送达待接收、异常/延误，填写跟进说明；保留操作者与时间。
3. 「登记接收」：仅填本次实际收到数量，未到的行填 0。每次接收增加目的仓库存、减少待收/在途；供应商货件同时更新采购到货量。
4. 待发货件可取消，释放库存占用或采购分配；已发出货件不能直接取消。

「已送达待接收」仅表示物流节点，不会自动入库；必须明确登记接收数量。未结束且超过预计到货日期的单据显示「已逾期」。每个货件详情展示最近 200 条跟进记录，历史事件继续保存在数据库。

## 库存口径

| 指标 | 计算与影响 |
|---|---|
| 仓内实物 | 已入库且尚未出库的数量，含被计划占用部分 |
| 计划占用 | 尚未发出的仓库货件预留数量 |
| 当前可用 | 仓内实物减计划占用 |
| 运输在途 | 已发出货件的数量减累计接收量，排除待发和取消货件 |

例如采购 100 件，供应商本批发 60 件并接收 40 件：国内仓实物 40、供应商在途 20。国内仓再计划发出 25 件：实物仍为 40，占用 25、可用 15。确认发出后实物变为 15，此货件在途 25；目的仓接收 20 件后，目的仓实物 20、该货件在途余 5。

库存摘要汇总当前店铺范围全部仓库；余额列表可以另按仓库及商品搜索。FBA 仓数量是人工接收的账面库存，不代表亚马逊实时可售数量，不从销售订单自动扣减。

## 期初与调整

每个店铺 + 仓库 + 商品组合没有历史流水时可登记一次正数期初。之后的盘点差异通过「库存调整」登记：增加填正数，减少填负数，原因必填。不能调整为负库存，也不能减少已被货件占用的数量。

所有占用、释放、出库、接收和调整都保存流水，包含数量变化、变动后实物/占用、来源单据、原因、操作者和时间。已过账流水没有编辑、删除入口；纠错记录新的差异调整。

建单、发出、取消计划、接收、物流事件和库存调整均有请求编号保护。相同请求重试不重复记账；同一编号用于不同内容时拒绝。PostgreSQL 使用一致锁顺序、唯一约束与条件更新，避免并发超分配或超收。

## 权限

| 角色 | 采购 | 发货与库存 | 金额 |
|---|---|---|---|
| 管理员 | 全部 | 全部 | 可见 |
| 经理 | 授权店铺维护 | 授权店铺收发货、调整，维护仓库 | 可见 |
| 财务 | 授权店铺维护 | 授权店铺只读 | 可见 |
| 仓库 | 授权店铺只读 | 授权店铺收发货、调整，维护仓库 | 单价、采购总额和付款约定不可见 |
| 运营 | 不开放采购 | 授权店铺发货与库存只读 | 不可见采购金额 |

新权限随现有角色生效；旧页面刷新或重新登录即可获取最新菜单。非管理员没有分配店铺时，业务列表为空。

金额审批、质检/供应商退货、库存批次、装箱、头程费用分摊、FBA 快照导入、采购应付与自动补货继续按开发计划推进，本次没有把 M5/M6 整体标为完成。
