# 商品、供应商与采购报价管理

## 使用入口

登录 ERP 后，左侧进入「商品管理」「供应商管理」「采购报价」。这三类资料是公司共享基础档案，页面不按顶部店铺或经营日期过滤。当前商品 ASIN、FNSKU 是来源参考标识；品牌不用于自动建立店铺授权。

### 商品管理

- 支持中文/原名称、内部 SKU、品牌、分类、材质、规格、图片、Listing 标题/描述/卖点及参考售价的新增和编辑。
- 搜索支持品名、SKU、ASIN、FNSKU，另可按品牌、启停状态和待核对状态筛选。
- 「详情 → 导入来源与原值」保留原 CSV 字段、文件名和行号。来源 stock、monthly_sales、评分等没有指定库存快照或统计期间，不会变成 ERP 当前库存、销售或利润。
- 「编辑 → 售价与核对」可逐条处理待核对说明。核对完成后移除相应说明，原始来源数据继续保留。
- 停用保留历史档案，不提供硬删除。

### 商品 CSV 导入

选择「导入商品 CSV」，使用本次商品来源导出格式；编码为 UTF-8，最多 2000 行。售价单位可选「未确认」「美分」「美元」；未确认时保留原值并将参考售价留空。

上传后先预览新增、跳过、错误和待核对行，再确认入库。存在数据错误时整批禁止确认。已有内部 SKU 跳过，不覆盖人工修改；同一批次重复确认不重复创建商品。FNSKU 重复时提示核对，保留不同 SKU 的独立档案。

该入口仅处理商品目录，订单、广告和库存报告仍属于后续导入中心范围。

### 供应商管理

维护供应商编码、名称、联系人、电话、邮箱、地址、付款约定和备注。名称忽略大小写后唯一；原供货资料中的 X / x 统一归档。实际公司名称或联系方式未提供时保留空值。

在供应商详情中可查看和维护关联采购报价。采购价格和报价原文应放在报价中，避免放进共享商品备注或可供仓库查看的供应商基础备注。

### 采购报价

一条报价对应一种包装/计价规格，可以关联多个商品。不同卷数、张数、尺寸或包装的单价分别保存。列表支持供应商、关键词、启停、核对状态和未关联商品筛选。

- 阶梯档位分别记录起订数量、报价单价、另列的含税价格、计价单位和档位备注；金额最多 4 位小数。
- 来源未给起订量或价格时留空，不自动填 1 或 0。
- 运费/贴标费是否包含使用「是 / 否 / 未注明」；贴标费单独留存，未自动叠加到报价。
- 不按税率推算或改写来源含税价格。疑似错误保留原数值、原文和待核对说明。
- 报价可以暂不关联商品，待商品或包装规格确认后再关联。
- 供应商原始报价与参考售价、正式核算成本分别保存；编辑报价不会自动改动库存成本或利润。

## 角色权限

| 能力 | 公司管理员 | 店铺主管 | 运营 | 财务 | 仓库 |
| --- | --- | --- | --- | --- | --- |
| 查看商品 | 是 | 是 | 是 | 是 | 是 |
| 新增、编辑、导入商品 | 是 | 是 | 是 | 否 | 否 |
| 查看供应商基础档案 | 是 | 是 | 否 | 是 | 是 |
| 管理供应商 | 是 | 是 | 否 | 是 | 否 |
| 查看、管理采购报价及原文 | 是 | 是 | 否 | 是 | 否 |

报价接口同时要求报价权限与成本查看权限，前后端都进行检查。操作审计记录变更，不将采购金额或原文复制到通用日志。

## 本地资料初始化

本次原 CSV、供货表的结构化整理、导入回执及迁移前备份存放在被 Git 忽略的 `.local/`。仓库仅保存通用导入脚本和合成测试数据。

`scripts/import_catalog.py` 通过已登录的本地 API 执行导入，要求有商品、供应商及报价管理权限。先用 `--check` 核对文件及 SKU 关联，再去掉该参数导入：

```bash
.venv/bin/python scripts/import_catalog.py --products /path/to/products_rows.csv --suppliers /path/to/supplier-manifest.json --price-unit unknown --check
```

供货清单 JSON 包含 `suppliers`、`quotes` 和可选 `products` 补充说明。供应商按编码/名称识别，报价按 `source_reference` 识别；重复运行跳过已有档案和报价，保留人工编辑。整批商品确认使用数据库事务，供应商和报价按条提交；运行中断后可以重跑续建尚未创建的记录。不要同时运行两份初始化脚本。

完整字段约定见 [接口约定](catalog-api-contract.md)。日常商品/供应商维护通过网页完成，不需要操作脚本。
