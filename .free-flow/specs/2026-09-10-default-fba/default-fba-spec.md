# 默认 FBA 仓库

依据用户 2026-09-10 指令「把所有仓库相关的都默认改为FBA仓库，具体哪个FBA仓不用关心」。

## 行为

- 新建发货默认供应商直发 FBA；目的仓和期初/调整仓库不再要求选择。
- 后端复用最早的启用 FBA 仓，没有时在业务事务中并发安全建仓；保留显式 ID 兼容和来源/目的不同的约束。
- 仓库模型、请求及新增表单默认 FBA。
- 库存余额、流水、摘要统一默认 FBA 类型范围；可查看全部历史仓库。
- 不改写历史库存和单据，不合并具体仓库，保留店铺隔离与不可编辑流水。
