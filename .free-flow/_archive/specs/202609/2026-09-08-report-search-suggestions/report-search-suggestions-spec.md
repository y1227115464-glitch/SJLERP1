## 1. 目标

销售记录与广告数据搜索框增加 SKU 候选。聚焦空输入显示列表，输入只更新匹配候选；选择 SKU 后确定查询并更新明细及汇总。保留回车/搜索按钮确认其他关键词的方式。

## 2. 方案

- 独立 ReportSearch 组件共享两类页面；区分输入草稿和已确认条件，选择使用精确 SKU，避免 SKU-A 混入 SKU-AB。清除按钮恢复未搜索状态。
- 新增 /sales-records/suggestions 与 /ad-records/suggestions 只读接口，按授权店铺及当前日期、销售状态或广告粒度返回去重 SKU。空 q 返回候选，有 q 按 SKU 包含匹配，最多 50 条并提示继续输入；查询直接投影 SKU，不拉全量记录。
- 原列表和摘要增加可选 sku 精确筛选，沿用 q 关键词搜索，两端过滤一致。无数据迁移或新依赖，不改导入/金额/权限规则。
- 候选只在展开时查询，输入防抖，晚到响应和切店/日期变化不能展示旧候选。支持鼠标和键盘选择、无匹配和加载/失败提示。

## 3. 验收

1. 聚焦空框显示实际报表中的唯一 SKU，输入后仅显示匹配项，输入过程中列表不自动执行搜索。
2. 选择后明细与汇总精准限定 SKU；鼠标、方向键+回车、直接回车/按钮关键词确认与清除均可操作。
3. 候选授权、日期、状态、广告粒度正确，特殊字符按字面匹配，返回数量有界。
4. 后端测试、前端构建、独立评审和隔离浏览器验证通过，备份更新既有局域网服务并保留业务数据。
