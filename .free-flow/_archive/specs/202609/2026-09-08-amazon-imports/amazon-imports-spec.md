## 1. 目标

支持所给销售 TXT（制表符）和商品推广 XLSX：选择店铺、上传、预览新增/更新/跳过/冲突、确认入库、查看批次及销售/广告数据。重复和重叠销售导入不得累计重复订单明细。

不自动把这两份文件写入正式店铺；店铺归属由用户导入时选择。不将广告归因销售额累加到订单销售额，不生成利润、财务结算或扣库存；暂不适配搜索词、结算、发货、退款等其他报告。无店铺 SKU 映射时按原 Seller SKU/ASIN 保留，不虚构商品映射。

## 2. 方案

现状：商品 CSV 有独立预览确认；没有销售/广告事实和导入中心。变化：新增 app/reports 模块，ReportImport、SalesRecord、AdRecord；独立前端导入与结果页面，复用身份、店铺范围、审计和请求限制。

- 样本销售 354 行，352 个订单，订单+SKU 无重复，含 Amazon.com / Amazon.ca、USD / CAD；去重键为店铺+销售渠道+amazon-order-id+sku。无 order-item-id，文件内同键完全相同行折叠，同键不同内容报冲突，避免猜测同 SKU 拆行。
- 跨批次同键相同规范内容跳过；last-updated-date 更晚才更新；更旧跳过；同更新时间不同业务内容报冲突。金额为空保留为空，取消行可无币种；金额按币种分组，不用店铺默认币种填空，不把 item-price 再乘 quantity。
- 销售原始时间有时区，统一保存 UTC。保留订单/商品状态、履约、商品、金额税费折扣与来源批次；业务列表不展示收件城市、邮编或买家标识。
- 广告样本为 2026-06-01 至 06-30 的 41 行、7 天归因商品推广数据，保留起止日期与广告组合/活动/组/SKU/ASIN/国家/零售商/币种。去重身份不含广告组合（可变组织属性）；相同身份和区间更新指标，不累加。无活动 ID 的报告以名称为身份，不猜测重命名。
- 同广告身份的非相同重叠区间拒绝入库，防止日/月混加；整批原子确认。预览后发生并发变化重新比对，若结果改变要求刷新预览并再次确认。广告同值确认也推进最新上传版本时间，旧预览不能覆盖已确认的新版本；源报告没有生成时间，因此重新上传旧文件仍视为新上传，用户需核对。
- 文件 20 MB，解压 XLSX 50 MB，最多 10000 行；修正样本错误的 A1 worksheet dimension 以读取全部数据；禁止公式单元格、宏和异常文件。保留源文件于私有存储，规范数据与错误分页展示，不一次渲染全表。金额 Decimal 四位小数；浮点尾数规范舍入，不平均比率。
- 导入/查看允许管理员、经理、运营和财务，限已授权店铺；仓库角色无权访问。批次可在授权店铺查看，只有上传者可确认。确认先复核账号/授权和店铺状态，按店铺行锁串行化导入、唯一约束兜底；重复确认返回既有结果。
- 批次暂存解析结果、来源哈希、解析版本、预览比较指纹、确认结果；源文件哈希辅助追溯，不代替自然业务键。确认失败回滚整批，原始/旧批次数据保留追溯。

## 2.5 结构健康度

结论：现状接入点可沿用，新业务独立 reports 目录，不扩充偏大的 routes.py / models.py / catalog_import.py。卸载需处理报表数据、移除新路由/权限/菜单/迁移注册；既有商品和库存不依赖此模块。

## 2.6 接口

统一 /api/v1，session、Origin、X-Requested-With 和写操作 X-CSRF-Token。

- POST /report-imports/preview multipart(kind=sales|ads,store_id,file)
- GET /report-imports、/{id}、/{id}/rows 分页；POST /{id}/confirm(verification_token)
- GET /sales-records、/ad-records 分页与店铺/日期/搜索筛选；日期语义销售按 UTC 下单日期，广告只选完整位于筛选期间内的报告区间。
- GET /sales-records/summary、/ad-records/summary 按币种分组及状态说明，CTR/CPC/ACOS/ROAS 从汇总分子分母计算，零分母为空。

例：先导入订单 A/SKU1 1 件，再导入含 A/SKU1 与 B/SKU2 的重叠报表，结果新增 1、跳过 1，列表共 2 行；A 状态更新时间更晚则更新 1，不新增第 3 行。

## 2.7 上线

新增 XLSX 解析依赖及三张表迁移，备份现有本机 PostgreSQL、构建前端、重启既有局域网服务。不导入正式业务数据、不提交用户文件或凭据。

## 3. 验收契约

1. 两份原始样本解析数量 354 / 41，表头尾空格、XLSX 错误 dimension、浮点尾数均可处理；取消空金额保留，跨站/币种不混。
2. 相同文件、改文件名、不同日期重叠、不同账号同店铺导入均不重复销售；较新更新、旧数据跳过、同时间冲突明确；并发确认仅一份事实。
3. 错列、损坏/空文件、重复冲突、非数/负数量/无时区、公式、超限均明确错误，不部分写入。
4. 广告相同期间更新，不同重叠区间拒绝；汇总金额分币种，比率重新计算，不能把月汇总拆为日报。
5. 预览不能直接变更事实；确认幂等，预览过时重检；跨店铺列表/批次/确认/摘要拒绝或空结果；仓库不可读。
6. 页面上传、错误、预览、确认、批次、查询和筛选可操作；类型构建、SQLite/PostgreSQL 测试、隔离浏览器与本机局域网回归通过。
